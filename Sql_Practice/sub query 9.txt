What is a Subquery?

A Subquery means a query inside another query.
The inner query runs first, and its result is used by the outer query.

CREATE TABLE emp (
    emp_id INT AUTO_INCREMENT PRIMARY KEY,
    e_name VARCHAR(50),
    dept VARCHAR(30),
    salary INT
);


INSERT INTO emp (e_name, dept, salary) VALUES

SELECT * FROM emp;



1️⃣ Inner and Outer Query Example (Simple Subquery)

Goal: Find employees whose salary is greater than the average salary.

👉 Step 1: Find average salary

SELECT AVG(salary) FROM emp;


Let’s say it gives 48000.

👉 Step 2: Use it in another query

SELECT e_name, salary
FROM emp
WHERE salary > (SELECT AVG(salary) FROM emp);


(SELECT AVG(salary) FROM emp) → Inner Query

SELECT e_name, salary FROM emp WHERE ... → Outer Query

What is a Multi-Row Subquery?

👉 A multi-row subquery is a subquery that returns more than one value (more than one row).
Since it gives multiple results, you can’t use = — instead, you use operators like:

Operator	Meaning
IN	Matches any value in a list
ANY	Compares with each value, condition true if true for any one
ALL	Compares with each value, condition true only if true for all



mysql> SELECT e_name, dept
    -> FROM emp
    -> WHERE dept IN (SELECT dept FROM emp WHERE e_name IN ('Raj', 'Sita'));
	
	
	

Step 2: Multi-Row Subquery using IN
✅ Example 1:

Find employees who work in the same department as “Raj” or “Sita”.

SELECT e_name, dept
FROM emp
WHERE dept IN (SELECT dept FROM emp WHERE e_name IN ('Raj', 'Sita'));


🧠 Inner query → returns multiple departments (IT, Finance)
Outer query → shows all employees working in those departments.




Step 3: Multi-Row Subquery using ANY
✅ Example 2:

Find employees whose salary is greater than any salary in the HR department.

SELECT e_name, salary
FROM emp
WHERE salary > ANY (SELECT salary FROM emp WHERE dept = 'HR');


🧠 Inner query returns HR salaries → (30000, 35000)
Outer query checks: salary > any one of them → salary > 30000 → true for all above 30000.




Step 4: Multi-Row Subquery using ALL
✅ Example 3:

Find employees whose salary is greater than all salaries in the HR department.

SELECT e_name, salary
FROM emp
WHERE salary > ALL (SELECT salary FROM emp WHERE dept = 'HR');


🧠 HR salaries = (30000, 35000)
Condition → salary > 35000



| Operator | Works With      | Meaning                                         | Returns           |
| -------- | --------------- | ----------------------------------------------- | ----------------- |
| **IN**   | Multiple values | Match any value in list                         | True if any match |
| **ANY**  | Multiple values | True if condition true for *at least one* value | Flexible          |
| **ALL**  | Multiple values | True if condition true for *every* value        | Strict            |






3.What is a Correlated Subquery?

👉 A correlated subquery is a subquery that depends on the outer query for its values.

That means the inner query runs once for every row of the outer query.

💡 In simple terms:

The inner query uses values from the outer query while it executes.

note:



What EXISTS Does

👉 The EXISTS condition in MySQL returns TRUE if the subquery returns at least one row.

That’s it.
It doesn’t care what data is returned — only whether any row exists or not.

SELECT * 
FROM a1 
WHERE EXISTS (
  SELECT 1 
  FROM a a2 
  WHERE a1.accno = a2.accno
);


| Outer Query           | Inner Query                     |
| --------------------- | ------------------------------- |
| FROM `a` AS `a1`      | FROM `a` AS `a2`                |
| Each row of a1        | compared to all rows of a2      |
| `a1.accno = a2.accno` | checks if a matching row exists |
