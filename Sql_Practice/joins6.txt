
A JOIN combines rows from two or more tables using a related column between them.

_______________________________________________
extracting info from multiply tables : joins

condition:
u shud hv one related column   ->“Common columns are the columns that store the same type of information in both tables —
they are used in the ON condition to join the tables.”

____________________________________________________-
1.inner (common records)

Returns only rows that have matching values in both tables.

ex:
 select * from a inner join b
     on a.accno = b.accno;

note : u shud mention a.ccno ,b.accno ->    bec how it wl get to know bec both columns hv same name

INNER JOIN = Common rows from both tables.

_______________________________________________________--



🔹 2. LEFT JOIN (LEFT OUTER JOIN)

Definition:
Returns all rows from the left table and matching rows from the right table.
If no match, shows NULL.

LEFT JOIN = All from LEFT + matching from RIGHT.


 select * from a left join b
    on a.accno =b.accno;



_________________________________________________________

3. RIGHT JOIN (RIGHT OUTER JOIN)

Definition:
Returns all rows from the right table and matching rows from the left table.
If no match, shows NULL for left table columns.

RIGHT JOIN = All from RIGHT + matching from LEFT.



 select * from a right join b
    on a.accno =b.accno;


_______________________________________________

4. FULL JOIN (FULL OUTER JOIN) -oracle
CROSS JOIN 

Definition:
Returns all rows from both tables,
shows NULL where there’s no match.

FULL JOIN = All records from both tables.


select * from a cross join b
    on a.accno =b.accno;


note:(⚠️ MySQL doesn’t support FULL JOIN directly;
you can use UNION of LEFT + RIGHT joins.)

-- 3. JOIN Examples
-------------------------------------------------

-- 3a. INNER JOIN (only matching rows)
SELECT s.student_name, t.teacher_name, c.class_name
FROM students s
INNER JOIN teachers t
    ON s.class_id = t.class_id
INNER JOIN classes c
    ON s.class_id = c.class_id;

-- 3b. LEFT JOIN (all students + matching teachers)
SELECT s.student_name, t.teacher_name, c.class_name
FROM students s
LEFT JOIN teachers t
    ON s.class_id = t.class_id
LEFT JOIN classes c
    ON s.class_id = c.class_id;

-- 3c. RIGHT JOIN (all teachers + matching students)
SELECT s.student_name, t.teacher_name, c.class_name
FROM students s
RIGHT JOIN teachers t
    ON s.class_id = t.class_id
RIGHT JOIN classes c
    ON t.class_id = c.class_id;

-- 3d. CROSS JOIN (all combinations of students and teachers)
SELECT s.student_name, t.teacher_name
FROM students s
CROSS JOIN teachers t;

-------------------------------------------------
-- 4. Notes:
-- INNER JOIN: only rows where class_id matches in both tables
-- LEFT JOIN: all rows from left table + matching rows from right table
-- RIGHT JOIN: all rows from right table + matching rows from left table
-- CROSS JOIN: Cartesian product (all possible combinations)
